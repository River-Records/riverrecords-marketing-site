# Content Signals — https://contentsignals.org
#
# A preference, not an enforcement mechanism. Crawlers may ignore it; blocking is a
# separate concern handled at the edge.
#
#   search=yes     index us and show links and short excerpts
#   ai-input=yes   use our pages to ground AI answers — RAG, AI Overviews, assistants
#   ai-train=yes   models may train or fine-tune on this content
#
# ai-input is deliberately YES, which is the opposite of the common default.
# This site is written to be quoted: /faq exists because question-shaped queries are what
# answer engines pull from, and the pricing and comparison pages carry schema for the same
# reason. Asking not to be used as AI input would switch off a channel we built for.
#
# The usual argument for ai-input=no is that AI answers cannibalise clicks. That applies
# to sites monetised by pageviews. Here, search sends ~60 clicks a month and the goal is
# that a clinician learns Stream exists — a cited answer is worth more than the visit it
# replaces. Revisit if that stops being true.
#
# ai-train was NO until 23 September 2026, on the reasoning that there is no return in it
# and that, unlike ai-input, it puts our name in front of nobody. That second half was
# wrong. Training data is exactly how a model comes to mention Stream unprompted, and the
# constraint on this business is that almost nothing outside this domain says we exist —
# no G2 listing, absent from every industry roundup, cited as a source in AI answers that
# then recommend competitors. Being in the weights is one of the few routes that changes.
#
# The rest follows: no pageview revenue to lose, the signal is a preference nobody
# enforces, and the coding guides here are more careful than most of what is currently
# training on this subject.
#
# The one asymmetry, stated plainly: there is no un-training. Whatever is scraped while
# this says yes is in there. Reversible as a declaration, not as a fact.
#
# It also ends a contradiction. Cloudflare emits its own content-signal header on
# converted markdown saying ai-train=yes, so until now the site published both answers
# and served the opposite one to the agents the signal exists for.
